# 独立包验证记录（2026-11-10）

本次在 aarch64 Linux / ROS 1 Noetic 上建立只含 `igo_local_planner` 的新 catkin
工作区，使用标准 ROS 导航依赖完成 Release 构建。没有叠加原整车工作区的构建产物。

| 检查 | 结果 |
|---|---|
| catkin 构建、动态配置生成、安装 | 通过 |
| CTest 核心场景 | 8 项场景通过，含前进/倒车延迟停车 |
| pluginlib 按导出名称创建实例 | 通过 |
| 仅使用 install 空间发现并加载插件 | 通过 |
| 动态库未解析依赖/符号 | 无 |
| 安装后的 `move_base + Navfn + IGO` 模拟闭环 | 3 个目标全部 SUCCEEDED |

ROS 仿真使用独立网络/PID 环境、回环 ROS master、合成空地图及理想运动学底盘。
三个目标依次为固定前进、固定倒车和自动方向选择；位置容差 0.20 m、朝向容差
0.25 rad。终点位置误差依次为 0.1960, 0.1939, 0.1997 m，
属于该模拟底盘的到点结果。没有发送实车目标或启动整车导航。

核心场景还验证了完整外廓内部障碍、未知区域策略、不可避免的制动碰撞、
转向变化率、曲线制动及过零换向。局部绕障场景使用单独的合成障碍地图。

本机 ROS 控制回调共 261 条，P95 28.27 ms、最大 32.75 ms。
该数据包含参考处理、地图拷贝和优化，是本机 CPU 仿真测量，不能替代其他主机的性能测试。
