# IGO 阿克曼局部控制算法

本文对应 [src/core.cpp](../src/core.cpp) 与 [src/ros_planner.cpp](../src/ros_planner.cpp) 的当前实现。优化核心只依赖 C++ 标准库；ROS 层负责接收全局路径、读取位姿与反馈、拷贝局部代价地图以及返回速度。

## 一个控制周期

```text
全局路径 + 当前 TF 位姿 + 实际速度/可选轮角 + 局部 costmap/footprint
  -> 转换参考路径并截取前瞻段
  -> 判断终点朝向约定与到点制动阶段
  -> 为允许的方向生成参考、绕行、低速和上周期初值
  -> 高斯采样、阿克曼预测、碰撞检查、按代价排序更新分布
  -> 比较优化结果与制动候选
  -> 返回最佳可行轨迹的第一步 v、omega
```

全局路径的几何不由 IGO 修改。局部绕行通过控制序列实现；输出轨迹仍受参考线偏离代价和沿路径进度奖励约束。算法运行于 CPU。

## 状态、控制和参考线

状态为 `s = (x, y, yaw, v, omega, steering)`，控制结点为 `(v, curvature)`。默认在 4 s 时域内放置 10 个结点，共 20 个优化变量，结点之间线性插值。

车辆关系采用：

```text
steering = atan(wheelbase * curvature)
omega    = v * curvature
x_next   = x + v_next * cos(yaw + 0.5 * omega_next * dt) * dt
y_next   = y + v_next * sin(yaw + 0.5 * omega_next * dt) * dt
yaw_next = wrap(yaw + omega_next * dt)
```

首步 `dt` 取 ROS 控制周期，之后预测步长为 0.2 s，末步截到时域边界。碰撞检查会在这些步之间进一步细分。

ROS 层使用当前可用 TF，将全局路径转换到局部代价地图坐标系；不沿用过期的路径发布时间做 TF 查询。参考段游标向前推进，前瞻长度由 `max_global_plan_lookahead_dist` 控制。预测中的路径匹配也按上一次匹配的段向前搜索，并限制局部搜索弧长，减少交叉路线和折返扫线中跳到另一段的情况。

`global_plan_overwrite_orientation=true` 时，中间参考点使用路径切线朝向，末点保留输入朝向；倒车时跟踪朝向项相应加 π。关闭该选项后，沿用路径提供的车身朝向，适合上层明确给出倒车姿态的参考路径。

## 运动约束与轮角反馈

`Optimizer::advance()` 依次结合：

- 前进/倒车速度上限与任务方向；换向先使当前速度到零。
- 线加速度与预测制动减速度。
- 最小转弯半径、偏航角速度和偏航角加速度。
- 前轮最大角度 `atan(wheelbase / min_turning_radius)` 及转角变化率。

转向时，线速度变化与角速度约束相互耦合。若请求速度变化会让可行曲率区间为空，算法沿当前速度到请求速度之间搜索较小的可行变化，而不是在最后单独截断偏航角速度。曲线制动还保留足够速度，使偏航角速度能按允许的角加速度逐步下降。

收到新鲜的实际前轮角反馈时，以该值初始化状态，零速也能保留真实轮角。否则运动中由 `atan(wheelbase * omega / v)` 估计；零速且没有轮角反馈时取零。零速度指令保持预测中的当前轮角，不生成原地旋转。

以上针对与配置包络相容的输入状态执行约束耦合。源码也处理已超出配置范围的反馈状态：优先保留几何界限并向包络恢复；不能把任意不一致输入都视为满足全部单步约束的初态。

## 指令减速与物理制动预测

当前实现分别计算速度指令和物理状态。制动时，指令的变化使用 `acc_lim_x`，物理状态预测使用较弱的 `decel_lim_x`。这样可以及时下发低速/停车设定值，同时按实际减速度评估车辆还会前进多远，避免将弱制动参数同时施加给设定值而形成逐阶降速。

接近终点时，根据剩余路径长度和直线距离的较大值计算速度限制。令：

```text
d = max(0, remaining_distance - min(0.2, 0.4 * xy_goal_tolerance))
a = decel_lim_x
tau = stopping_delay
v_limit = sqrt((a * tau)^2 + 2 * a * d) - a * tau
```

该式对应 `v * tau + v² / (2a) <= d`，把停车点放在位置容差内部。若要求精确朝向且近终点朝向仍差得较多，保留机动空间，不直接将所有近目标运动压成停车。

位置与朝向进入容差后，ROS 层锁定 `goal_braking` 阶段，让同一优化器继续选择经碰撞检查的制动轨迹。车辆仍在滚动时越出容差，不立刻重新加速或切换方向；完全停下后若仍在容差外，才重新接近。只有位置/朝向条件成立且 `|v| <= 0.05 m/s`、`|omega| <= 0.05 rad/s` 才报告目标完成。

默认 `decel_lim_x=0.18 m/s²`、`stopping_delay=1.2 s`。这两个数是当前配置值，新车辆需按实际制动和执行响应设置。

## 轨迹可行性

每个控制周期拷贝一致的局部代价地图快照。`Grid::prepare()` 构造硬障碍积分图，用于快速跳过无硬障碍的包围盒；包围盒内存在硬障碍时，对凸 footprint 与栅格做分离轴相交检测，覆盖轮廓内部和边缘。

栅格判定与源码一致：

| 栅格 | 处理 |
|---|---|
| 254 | 硬障碍 |
| 255 | 由 `treat_unknown_as_obstacle` 决定是否为硬障碍 |
| 0～253 | 参与软代价采样，数值最高按 252 计 |
| 地图范围之外 | 不可行 |

软障碍代价取 footprint 顶点与参考中心处的最大采样值；硬碰撞检测则覆盖整个多边形，二者不是同一种采样方法。

相邻预测位姿之间，根据“平移距离 + 外廓最大半径 × 转角变化”决定细分数，使检查间隔所对应的外廓运动不超过 `0.45 * resolution`。这是对有限分辨率地图的离散碰撞检查。

时域末端之后继续检查完整停车过程：先按当前速度/角速度推进 `stopping_delay`，再沿当前曲率减速至零，期间仍检查 footprint。停车延续只用于可行性判断，不计入所发布的时域内 `local_plan`。

碰撞轨迹得到较大的罚分，较长的无碰撞前缀可用于引导分布搜索；只有 `valid=true` 的轨迹能成为输出。若所有候选均不可行，插件返回失败给 `move_base`，并在 status 中说明原因。

## 代价函数

默认权重下，每个预测步累计以下项：

```text
dt * [
    path_weight * cross_track_error²
  + heading_weight * heading_error²
  + obstacle_weight * (footprint_soft_cost / 252)²
  + 0.04 * omega²
  + 0.02 * (v_next - v_previous)²
  + steering_change_weight * steering_rate²
]
```

到时域末端减去 `progress_weight * ordered_path_progress`。当当前参考段已包含全局终点时，还加入 `7 * terminal_position_error²`、`8 * terminal_speed²`，以及需要终点朝向时的 `3 * terminal_yaw_error²`。这些常数与四个可调路径权重共同构成当前实现，不是另一个外置决策器。

## 初值与高斯 IGO 更新

每个允许方向分别构造参考跟踪种子与左右绕行种子。当前实现还构造原速度 50% 和 25% 的连贯低速种子及对应左右绕行候选，使较长制动距离下的慢速绕行能直接参与搜索。上一周期的最佳控制序列向前平移一个控制周期后也作为初值候选。

这些候选都通过同一个预测、约束、代价和停车检查过程，不改变全局路径，也不放宽碰撞条件。

每轮从 `N(m, diag(variance))` 采样，按轨迹代价排序。最优 `floor(samples * elite_fraction)` 个排名获得归一化效用，至少保留一个；代价完全相同的样本平分该并列区间的排名效用。对每个优化维度执行：

```text
delta_i      = sample_i - m
m_new        = m + mean_rate * sum_i(weight_i * delta_i)
variance_new = variance + variance_rate *
               sum_i(weight_i * (delta_i² - variance))
```

更新使用约束映射之前的原始高斯样本；速度、曲率等约束在轨迹预测中生效。方差设置上下界，更新后的均值也重新评估。实现采用对角方差和有限候选，不承诺全局最优。

默认每方向每轮 48 个样本、4 轮。实际 `evaluations` 还包括初值、更新后均值以及停车候选，不等于简单的 `samples * iterations`。

最后额外比较四种零速设定候选：曲率为零、保持实测/估计轮角、左曲线制动、右曲线制动。它们仍经过完整运动约束与停车延续检查。所有方向和候选中代价最低的可行轨迹被选中，只执行其第一步；下一控制周期重新优化。

## ROS 协议与兼容行为

`setPlan()` 保留原路径；任务序号、终点位置/朝向改变时重置优化初值。更改方向、结点数或时域也会重置初值。普通路径按位置和 yaw 验收终点。

可选 yaw-free 协议要求自动方向模式、所有路径 pose 的 `header.seq` 相同，且高两位为 `10`（`(seq & 0xC0000000) == 0x80000000`）。该协议同时影响终点朝向代价与完成判定；固定前进/倒车不使用它。路径生产方需要显式保留此字段，常规 `move_base` 目标消息本身不保证全局规划器透传序号。

插件可从既有 `TebLocalPlannerROS` 命名空间继承未显式配置的通用车辆参数，并发布两条旧名称的 Path 显示别名。实际优化器、动态配置和状态均属于 IGO，构建及执行不依赖 TEB。

本仓库核心场景和 ROS 模拟闭环分别检查优化运动学与插件接入。实际车辆上的误差、停车距离及计算延迟应从相应运行记录测量；局部地图快照本身不含移动目标的未来轨迹预测。
